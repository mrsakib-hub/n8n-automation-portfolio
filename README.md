# n8n Automation Portfolio

Production-ready n8n workflows by **MR Autify**: AI agents, Gmail automation, lead generation and CRM systems that save businesses hours every week.

## Services

- **AI Agents:** custom agents with GPT, Gemini and Claude
- **Gmail Automation:** auto-replies, smart sorting, Telegram alerts
- **Lead Generation:** scraping, enrichment and outreach pipelines
- **CRM Systems:** Google Sheets and API-based CRM workflows
- **Integrations:** Telegram, WhatsApp, WordPress, Webflow, REST APIs

> Workflow JSON files and screenshots are added as each build is completed. All credentials and client data are removed.

## How to Use

1. Open n8n and choose **Import from file**.
2. Select a workflow `.json` file from this repo.
3. Add your own credentials (Gmail, Telegram, API keys).
4. Test, then activate.
